# 🏰 KrakoviaServer

Servidor oficial do **Krakovia**, um MMORPG desenvolvido durante uma game jam com duração de 30 dias.
https://www.youtube.com/watch?t=819&v=10xy_52HHik&feature=youtu.be

---

## 📌 Sobre o Projeto

**KrakoviaServer** é o backend responsável por gerenciar:

- Conexões dos jogadores  
- Sistema de autenticação  
- Sincronização de mundo  
- Combate  
- Inventário  
- Persistência de dados  
- Lógica principal do jogo  

O foco durante o desenvolvimento foi **funcionalidade e entrega dentro do prazo**, não arquitetura perfeita ou código altamente refinado.

---

## ⚠️ Aviso Importante

Este projeto foi desenvolvido em **30 dias**, com o objetivo de entregar um MMORPG funcional dentro do prazo da game jam.

Devido à limitação de tempo:

- Muitos commits foram feitos apenas para controle de versão rápido.
- As mensagens de commit podem não seguir um padrão.
- Algumas partes do código podem estar pouco organizadas ou sem refatoração adequada.
- Pode haver código experimental ou soluções improvisadas.

O versionamento foi utilizado principalmente como ferramenta de backup e controle incremental, não como histórico técnico formal.

---

## 🎯 Objetivo ao Tornar Público

- Compartilhar a experiência de desenvolver um MMORPG em 30 dias.
- Permitir que outros estudem a arquitetura e as soluções adotadas.
- Servir como base para experimentação ou expansão.
- Documentar o processo real (incluindo imperfeições) de um projeto sob pressão.
